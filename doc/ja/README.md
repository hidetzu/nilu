# Nilu リファレンスマニュアル

Nilu は、ホストプログラムに組み込むための小さなスクリプト言語です。Zig で書かれていて、
C のホストからは [`include/nilu.h`](../../include/nilu.h) 一枚で使えます。

Nilu は Lua 5.5 に着想を得た、別の言語です。多くを Lua から借りていますが、Lua の実装ではありません。
決めて変えたところは [13 章](13-differences-from-lua.md)にまとめてあります。

このマニュアルは **Nilu 0.1.0-dev.1** を説明します。
版の正本は [`include/nilu.h`](../../include/nilu.h) の `NILU_VERSION` です。

| | |
|---|---|
| 対象の読者 | `nilu` を手に入れた人。このリポジトリを読んだことがなくてかまいません |
| このマニュアルが答えること | **いまどうなっているか** |
| 答えないこと | **なぜそう決めたか**（[設計](../../design/README.md)にあります。英語です） |

## このマニュアルの約束

**ここに書かれた例は、すべて実際に実行されています。**

例は 2 つのブロックの対で書かれていて、`zig build manual-check` がこのマニュアルから
それを抜き出し、ビルドした `nilu` に通して、出力が書かれているとおりかを確かめます。
`manual-check` は `zig build check` の一部で、これはすべてのプルリクエストと `main` への
プッシュで CI が実行する完全なゲートです。例が一致しなければ、このゲートが落ちます。

````markdown
```lua nilu
print(1 + 2)
```
```output
3
```
````

囲みの最初の語 `lua` は色付けのためだけのものです（Nilu の構文は Lua 5.5 のものです）。`nilu` の語が、
実行する例であることを示します。

**書かれていないことは、約束されていません。** 逆に、まだ無いものは
「無い」と書きます — 「できません」ではなく「まだ実装していません」と書き分けるのは、
読んだ人の次の一手が変わるからです。
